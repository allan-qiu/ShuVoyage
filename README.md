# ShuVoyage · 蜀运成都

一个以成都文化与旅行体验为主题的中文静态网站。通过古蜀文明、川味美食、熊猫、茶馆与川剧，以及三日行程，帮助游客了解成都并安排出行。

## 页面内容

- **首页**：成都影像、主题入口、城市别名与抽签互动。
- **古蜀**：三星堆、金沙、都江堰的介绍、历史时间线与照片。
- **川味**：火锅与川菜介绍，支持按菜品类别和辣度筛选。
- **熊猫**：参观建议、活跃时段示意与周边游览地点。
- **茶与戏**：盖碗茶、茶馆生活、川剧与传统手艺。
- **三日行程**：按天切换的行程安排，第三天可切换近郊路线；附出发前清单。

## 快速开始

直接使用现代浏览器打开 `index.html` 即可浏览，无需安装依赖或执行构建命令。

也可以在项目目录使用本地静态服务器预览。如果电脑已安装 Python，可执行：

```powershell
cd "C:\Users\Administrator\Desktop\ShuVoyage"
python -m http.server 8000
```

然后访问 <http://localhost:8000>。按 `Ctrl+C` 停止服务器。

> 页面通过 Google Fonts 加载字体，需要网络连接；无法连接时会使用 CSS 中配置的后备字体。内容图片保存在本地。

## 技术与交互

使用 HTML、CSS 与原生 JavaScript 实现，没有前端框架、包管理依赖或后端服务。

- 通过页面锚点访问不同主题。
- 支持移动端布局，部分图片使用懒加载。
- 行程标签支持左右方向键切换。
- 出发前清单通过 `localStorage` 保存勾选状态，仅保存在当前浏览器，不会跨设备同步；浏览器禁用存储时可能无法保留状态。
- 页面包含减少动态效果偏好的适配。

## 修改与维护

**修改文字**：在 `index.html` 中搜索对应标题或正文并编辑。

**替换图片**：将图片放入 `img/`，修改对应 `<img>` 的 `src`；同时更新 `alt` 描述与图片尺寸。部分图片通过 `--ar` 设置展示比例、通过 `--op` 设置裁切位置，替换后应检查主体是否完整。

**调整样式与交互**：CSS 和 JavaScript 均内嵌于 `index.html`。交互脚本位于文件末尾的 `<script>` 中。

**发布网站**：将 `index.html` 与完整的 `img/` 目录一起上传至支持静态文件的托管服务，保持相对路径不变。

修改后建议检查桌面及手机宽度下的图片展示、菜品筛选、行程切换与清单保存功能。
